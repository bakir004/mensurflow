# Work log: 2026-11-07

Author: Aldin, with Codex assistance.
Branch: `aldin-branch`; forward activations and selection committed through `a196044`.
Per-operation cutoff policy, casts and documentation updates are in the working tree.

## Summary

Implemented CPU F32 forward activations `leaky_relu`, GELU (exact and tanh forms), SiLU, ELU and
softplus using one shared templated loop. Added F32 comparisons returning Bool and Bool/F32 `where`.
All follow the existing Tensor API → validation/packing → dispatcher → CPU adapter → kernel path.
The kernels use ordinary C++ and the existing OpenMP macro.

Added independent scheduling cutoffs for every CPU elementwise operation, including separate GELU
variants and dtype casts. Initial values retain 32,768 elements; measured per-operation tuning
remains pending. Added all 16 CPU casts among F32, I32, F16 and BF16 through the same dispatcher.

## What changed

1. Added activation parameters, CPU registrations, stable forward math, independent float64
   references, API/kernel tests and six benchmark variants.
2. Added broadcast comparisons `eq`, `ne`, `lt`, `le`, `gt`, `ge` and `where`, independent broadcasting
   and byte/bit references, API/kernel tests and the selection benchmark.
3. Added optional native C++ ATen comparisons through the existing benchmark harness. Both sides
   use the same preallocated buffers, requested thread counts and observation. The paired-log
   parser preserves run-to-run drift.
4. Added an internal cutoff table and a process-local override per operation. The elementwise
   kernels read their own cutoff before their OpenMP region. The existing activation/selection
   templates and public signatures are retained.
5. Added `--cutoff` to the elementwise benchmark executables and effective cutoff metadata.
   The arithmetic benchmark now also covers the remaining existing elementwise kernels. Native
   references print the installed ATen TensorIterator grain size.
6. Added `parallel_cutoff_test` for independent overrides, invalid configuration and kernel results
   around a small custom cutoff, forced serial execution and forced parallel execution.
7. Added public `cast`, `OpId::Cast`, CPU registrations by source dtype and a shared typed cast loop.
   The destination comes from the output tensor; dispatcher policy and `OpArgs` remain unchanged.
8. Added nearest-even F16/BF16 conversion, direct integer-to-float rounding, guarded float-to-I32
   conversion, bit-preserving identity casts, an independent long-double reference, exhaustive
   format/rounding tests and an optional native ATen `copy_` benchmark.
9. Documented current support in `docs/CAST.md` and tuning in `docs/PARALLEL_CUTOFFS.md`.
