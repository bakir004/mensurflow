# Team plan: 2026-11-20 to 2026-12-04

Two weeks. Goal: finish the remaining CPU functions in [`docs/KERNELS.md`](../KERNELS.md) before
the CPU milestone in mid-December, then the GPU. Bakir works on the infrastructure around the
kernels; Asja and Vedad write the kernels.

## Where we start

`KERNELS.md` was checked against `main` (`5dbcc58`) on 2026-11-20: every ticked item exists in
the code, and no unticked item does. Small fixes in the same commit:

- `argmin` has a parallel kernel too; `permute` works for any axis order, not only 2D.
- `sum_of_squares`, `any` and `all` were on the ticked `min`/`prod` line; they now have their own
  unticked line.
- `gelu` and `silu` have `gelu_backward` / `silu_backward`, but no autograd node.
- `Tensor::zero_grad()` exists (global-norm clipping does not); autograd's internal
  `reduce_gradient` does what `sum_to_shape` would, but there is no public op.
- Possible autograd bug, read from `src/core/autograd.cpp` and not yet tested: backward does not
  run in topological order, so an intermediate tensor used twice (a residual connection, `x * x`)
  passes only its first gradient upstream. Leaf tensors (parameters) do accumulate correctly.
  Vedad's first item checks this.

Done so far: all of P0, most of P1, P2 except the items below, P3 convolution, pooling and
normalization, and the P4 attention basics.

## Definition of done (same as before)

A sequential and a parallel version, dispatcher registration, public op, tests against a reference
in `tests/reference/`, a benchmark row, and a comparison with the best available implementation
(PyTorch, OpenBLAS and so on). See the [2026-11-04 plan](2026-11-04-plan.md) for the measuring rules.
